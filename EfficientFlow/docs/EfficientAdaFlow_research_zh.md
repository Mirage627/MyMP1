# EfficientAdaFlow：研究判断、验证计划与反馈记录

## 结论与研究定位

**方向值得试，但“EfficientFlow 加 AdaFlow”本身更接近一个合理的组合基线，尚不能据此认定有足够的新颖性发表新论文。** 这版实现的目的，是先建立公式、训练、采样和诊断一致的研究起点，再由实验决定应继续强化哪一部分。一次不成功可能来自训练、校准、求解器或任务设置；需要通过有区分力的对照定位，不能直接推出方法不可行。

两篇工作的互补点很清楚：EfficientFlow 用等变结构提高数据效率，用 FABO 降低生成流的曲率；AdaFlow 在推理时用条件速度残差的估计值分配积分步数。前者改变所学向量场，后者改变数值积分的计算分配。潜在收益是让已被 FABO 平滑的简单状态使用 1 步，同时将更多计算留给装配、接触或多模态决策状态。

更有研究价值的问题是：**经过 FABO 正则化后，残差指标是否仍能可靠地预测需要多少计算；这种计算分配能否在保持离散等变性的同时，改善成功率与实际时延的折中？** 如果只有平均 NFE 下降、成功率和时延均未改善，则还没有实质进展。如果相同延迟下稳定提高成功率，或相同成功率下稳定降低延迟，并能解释哪些状态从中受益，才形成比较可信的证据。

本仓库中的名称 EfficientAdaFlow 是便于实验的工作名称，不代表新颖性已经确认。

3. [Adaptive Time Step Flow Matching for Autonomous Driving Motion Planning](https://arxiv.org/abs/2602.10285)，2026。已在驾驶规划中使用轻量方差估计器在线调整积分计算，说明“方差控制步数”本身不是新的贡献。

6. [SeFA-Policy: Fast and Accurate Visuomotor Policy Learning with Selective Flow Alignment](https://arxiv.org/abs/2511.08583)，2025。用专家数据纠正重流后的观察与动作一致性，是另一个快速机器人流策略方向。

截至 2026-10-22 的这次定向检索，未找到明确宣称实现本仓库所讨论的完整 FABO、群不变残差头和独立自适应积分组合的原始论文；这不是全面查新证明。不能声称“首次自适应 flow policy”“首次等变 flow policy”，也不能因为检索不到完全同名的方法就认定存在论文贡献。正式写作前还应追踪上述工作的引用、后续版本及目标会议同期论文。

## 两篇方法实际估计的量

设专家动作序列为 `a`，初始噪声为 `z ~ N(0,I)`，观察历史为 `o`。条件直线路径为：

```text
x_t = (1-t) z + t a
u = a-z
L_FM = E[ ||v_theta(x_t,t | o)-u||² ]
```

理想的最优速度为 `v*(x,t|o)=E[u | x_t=x,o]`。AdaFlow 的标量条件方差对应整个动作序列的条件速度协方差的迹：

```text
sigma²(x,t | o)
    = E[ ||u-v*(x_t,t | o)||² | x_t=x,o ]
    = tr Cov(u | x_t=x,o)
```

它不是多个候选动作之间的经验方差，不是 FABO 损失，也不是预测动作的成功概率。尤其不能将“候选接近”直接解释成“动作正确”。

对有限训练、受 FABO 正则化的 `v_theta`，平方残差满足：

```text
E[ ||u-v_theta||² | x_t,o ]
    = tr Cov(u | x_t,o) + ||v*(x_t,t|o)-v_theta(x_t,t|o)||²
```

因此本版的头严格说是在估计**当前模型的条件残差能量**。它同时包含数据本身的多解性、观察歧义以及速度模型的拟合偏差。预测值高，可以提示减少步长，但更多积分步不能保证修复一个学错的向量场。

## 本研究版本的数值约定

### 归一化残差与方差头

设预测序列包含 `D = horizon * action_dim` 个标量。本版对每个样本使用：

```text
e = mean_over_time_and_action[(u - stop_gradient(v_theta))²]
log_q = invariant_head(stop_gradient(shared_features))
L_head = 0.5 * E[ e * exp(-log_q) + log_q ]
```

`q=exp(log_q)` 的目标是条件**平均平方残差**，是 RMS 尺度的平方。头的输入及速度残差均切断对主干的梯度，避免该 NLL 通过改变主干来压低自身目标，主干仍由 flow matching 和 FABO 训练。联合训练仍存在移动目标问题：速度模型变化时，残差分布也随之改变，所以必须保留只训练头的校准阶段作为对照。

AdaFlow 官方代码对时间和动作维度求和，并输出 `log_std`；其等价 NLL 为 `0.5*(e_sum/variance + log(variance))`。这里选择均值是为了降低动作维度和预测长度对阈值尺度的影响。因此**不能直接照抄论文中的 eta 数值**。若数据与模型完全相同，理想尺度换算为 `q_mean = q_sum/D`、`eta_mean = eta_sum/sqrt(D)`；实际仍应在验证集上调节。

默认 `eta=0.1` 只是首轮试验起点，不表示已经校准。日志中的方差、RMS 和误差必须记录采用的是均值约定还是求和约定。

### FABO 与损失尺度

在同一条件直线路径上取 `r=t+delta`：

```text
L_FABO = E[ (1-t)² * mean[(v_theta(x_t,t)-v_theta(x_r,r))²] ]
L_velocity = 2 * L_FM(r) + fabo_weight * L_FABO / delta²
```

本版默认保留原实现中 flow 项和 FABO 项的相对权重，再将原总损失除以 `delta²`，便于独立记录各项，并避免与新增头的尺度相差过大。对固定 `delta`，这是整体损失的常数缩放；但在 Adam 的 epsilon、梯度裁剪和有限精度下，优化过程不保证与原实现逐步相同。因此既要保留原 EfficientFlow 实验结果，也要有本版本的 `fixed` 求解器对照，分离训练实现变化与自适应采样变化。

训练时间取 `t in [0,1-delta]`，确保两次评估相隔真实的 `delta`，避免接近终点时截断导致有限差分尺度不一致。另有 10% 的训练样本将 `t` 置零，以覆盖从 `t=0` 开始的推理。这是本版的工程选择，也需要消融；不能将其收益全部归于自适应求解器。

FABO 惩罚的是生成流时间中的速度变化。它不等同于机器人真实执行时间中的关节加速度或末端 jerk。若要讨论执行平滑性，必须在 rollout 中额外测量实际动作变化。

### 自适应积分

每个候选轨迹分别维护时间 `t_i`、状态 `x_i` 和实际 NFE：

```text
dt_i = min( max(eta / sqrt(q_i), 1/max_steps), 1-t_i )
x_i <- x_i + dt_i * v_theta(x_i,t_i | o_i)
t_i <- t_i + dt_i
```

默认 `max_steps=8`，故 `dt_min=1/8`。最后一步允许小于 `dt_min`，以准确到达终点。已到终点的样本从活动批次中移除，后续网络评估只处理尚未完成的候选。各候选使用独立时间，因此不能将某个样本的时间或条件误配给其他候选。

`fixed` 使用同一向量场和等间距 ODE Euler 积分，是最关键的控制组。只在同一 checkpoint 上比较 fixed 与 adaptive，才能检验计算分配本身是否有效。

## 自适应采样的离散等变性

考虑实现中的有限循环群 `C_N`，而非直接宣称对任意连续旋转严格等变。假定：

- 群在动作坐标中使用正交线性表示，速度满足 `v(gx,t|go)=g v(x,t|o)`。
- 方差头满足 `q(gx,t|go)=q(x,t|o)`，所有阈值、裁剪、停止规则均由群不变量决定。
- 比较两次运行时使用配对噪声 `x'_0=g x_0`，观察和需要使用的历史动作也同时变换。

则两个运行在每一步具有相同时间、相同步长和停止时刻，并满足 `x'_k=g x_k`。证明可直接归纳：不变的 `q` 给出相同 `dt`；随后

```text
x'_(k+1) = g x_k + dt * v(g x_k,t|g o)
          = g (x_k + dt * v(x_k,t|o)).
```

本版对共享特征的群轴进行均值和二阶矩池化，再生成标量预测。群作用若确实只是该轴的置换，这两种统计量均为不变量。把展平后的群特征直接送入普通 MLP 则没有这项保证。

这是一条**结构命题**，不要求网络已经训练最优；它也不是性能或误差保证。实际数值测试仍需检查图像插值、随机裁剪、动作表示、normalizer 和历史候选筛选。逐坐标且不相容的缩放可能破坏正交表示下的等变关系。透视相机下旋转图像也不必然等同于真实三维场景的物理旋转。报告应区分模型表示的群等变性与真实环境中的旋转泛化能力。

若候选筛选使用欧氏距离，只有距离所用坐标度量与群作用相容、历史动作同步变换时，筛选才能继承上述结论。比较独立随机噪声的两次输出，不能用于判断逐样本等变误差；应使用配对噪声。

## 为什么不直接继承 AdaFlow 的误差定理

AdaFlow 的理论分析使用理想最优速度、相应的真实条件方差以及特定的正则性假设。其局部分布误差界与全局分析不能直接用于有限数据、受 FABO 偏置且方差头不完全准确的网络。最小步长的裁剪也意味着高残差时可能无法满足某个给定误差阈值。

另外，逐样本、状态依赖的时间网格与统一时间边缘分布之间的关系需要谨慎分析，不能将点上的 `eta/sqrt(q)` 当作已经证明的闭环控制安全边界。本版将其用作有论文动机的计算分配准则，通过校准与 rollout 实验检验效果。

可以准确主张的是：实现了群不变的调度指标和结构上保持群等变的离散积分；在给定预算内分配计算。能否提高行为质量必须由实验回答。

## 首轮实验矩阵

建议先做小规模、有区分力的实验，确认方向后扩展任务及数据量。

| 问题 | 最小对照 | 主要判据 |
| --- | --- | --- |
| 自适应是否有效 | 同一 checkpoint 的 fixed 1/2/3/5/8 步与 eta 扫描 | 成功率与实际延迟的 Pareto 曲线 |
| FABO 与适应性是否互补 | `fabo_weight=0`、默认权重分别使用 fixed/adaptive | 同预算成功率、残差校准、生成误差 |
| 联合训练目标是否漂移 | joint；冻结主干后 head_only | 分桶预测/实际残差、所需 NFE 分布 |
| 头是否影响主干 | fixed 模式比较新增头前后同训练设置 | flow loss、fixed 成功率；不得把训练变化误算为采样收益 |
| 起点训练是否必要 | 10% `t=0` 与均匀时间 | 首步残差与一步生成质量 |
| 候选数是否混淆收益 | 1 个与 5 个候选，各自 fixed/adaptive | latency、实际模型调用次数、成功率 |
| 阈值是否稳定 | 验证集 eta 扫描，例如 0.025/0.05/0.1/0.2/0.4 | 是否存在宽而稳定的有效范围 |
| 群不变调度是否正确 | 配对旋转观察和噪声 | q 差值、步长差值、动作等变误差 |

优先使用 Square D2、Threading D2、Three Piece Assembly D2 等对精度和决策更敏感的任务；同时保留 Stack D1 作为较容易的控制任务。如果 Stack 已经一步接近饱和，改善空间很小，不适合单独判断该研究是否有效。

第一阶段可用 100 demonstrations；得到稳定趋势后扩展 200、1000 demonstrations 及至少 3 个训练种子。比较时保持训练步数、数据划分、候选数、执行 horizon 和环境评估设置一致。校准与 eta 选择使用验证集，最终报告使用独立测试集。按 demonstration 划分，避免相邻帧泄漏到训练和校准两侧。

至少记录：

- 每个训练种子的成功率，以及跨种子的均值、标准差和评估 episode 数；不要只选一个最好 seed。
- 每个候选的 NFE 分布、P50/P95、1 步比例、到达最大步数比例；另记每次策略预测的批量网络调用次数。
- 端到端预测延迟 P50/P95，包括 encoder、方差头、积分、候选筛选；另记同步 GPU 计时的方法及是否已预热。
- 相同观察、初始噪声下，低步数结果相对高 NFE 积分结果的误差。高 NFE 结果只作为数值积分参考，不是专家真值。
- 预测 q 与实际平方残差的分桶曲线，并按 flow time、任务阶段和成功/失败分组。只看全局相关系数容易掩盖局部过度自信。
- 接触/抓取/模式选择附近与自由运动阶段的计算量；实际执行的动作跳变和 jerk 指标另行测量。

候选级平均 NFE 不是完整的速度指标。多个环境和候选组成批次时，慢样本可能延长整个调用；活动批次压缩也有索引和同步开销。GPU 很小的批次下，更少 FLOPs 也不保证更低延迟。

为减少 checkpoint 选择偏差，至少同时报告固定训练预算末尾模型和通过验证集选定的模型。若额外报告训练过程最高测试成功率，应明确标记，不能将其当作无偏的最终测试结果。

## 结果不理想时的优化路线

| 观察到的现象 | 优先排查 | 下一轮有区分力的尝试 |
| --- | --- | --- |
| fixed 8 步也很差 | 数据与动作归一化、训练收敛、表示或 FABO 偏置 | 先建立 `fabo_weight=0` 的可用 flow 基线；检查训练 batch 和 rollout 输入一致性 |
| fixed 多步好，adaptive 差且常为 1 步 | q 低估、eta 太大、校准样本覆盖不足 | 冻结主干做 head_only；减小 eta；按时间分桶看校准 |
| adaptive 经常到 8 步，仍不如 fixed 8 步 | 时间分配不合理、头校准错误、实际 dt 使用错误 | 同噪声保存完整时间网格；核查候选与 observation 对应；验证固定小步参考 |
| q 很大但增加 NFE 无益 | 向量场拟合偏差、不可约多模态残差与数值误差混淆 | 降低 FABO；与高 NFE endpoint error 对比；考虑专门学习积分误差指标 |
| joint 不稳，head_only 正常 | 残差目标持续漂移、头学习率或尺度不适合 | 延后训练头、分阶段校准；用独立优化器/学习率做受控消融 |
| 全局校准正常，接触处过度自信 | 稀有状态、视觉歧义或局部信息被池化丢失 | 按阶段重采样校准数据；增强保留时间结构的群不变头 |
| 成功率提升但延迟没降 | encoder 固定开销、压缩开销、少数高 NFE 样本 | 分解计时；降低候选数对照；比较预算档位/批内调度，重新检查等变性 |
| 少样本下收益大，多数据下消失 | 数据效率收益与数值收益混在一起 | 分开画数据规模和 NFE 曲线，判断论文主张应侧重何处 |
| 一个任务有效，其他任务无效 | 超参数迁移性、数据多模态程度、任务天花板 | 固定验证规则跨任务评估；报告失败任务，避免逐任务过拟合阈值 |
| 旋转后 q 或 NFE 改变 | 头未真正不变、随机图像处理、normalizer 不相容 | 使用配对输入与确定性预处理，逐层检查群作用 |

可考虑的后续研究扩展包括：基于验证集的全局或分时间校准；在不变表示上预测高 NFE 参考的局部积分误差；联合残差与沿采样轨迹测得的曲率信息；针对高歧义区域调节 FABO 权重以保留模式。这些均属于待验证假设。尤其“残差大就削弱 FABO”会引入自反馈和数据拟合偏差，需独立消融后才能成为方法主张。
